# 🏦 Banking Management System

A Banking Management System developed using **MySQL** that simulates real-world banking operations such as customer management, account handling, transactions, loans, EMI payments, cards, beneficiaries, and fraud monitoring.

---

## 📌 Project Overview

This project demonstrates the implementation of SQL concepts using a Banking Management System database. It is designed using proper relational database principles with Primary Keys and Foreign Keys.

The system manages:

- Customers
- Branches
- Account Types
- Accounts
- Employees
- Beneficiaries
- Cards
- Transactions
- Loans
- EMI Payments
- Fraud Alerts
